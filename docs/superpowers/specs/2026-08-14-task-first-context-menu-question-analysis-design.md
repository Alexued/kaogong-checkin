# 任务优先、触点菜单与全量资料分析题库设计

## 目标

- 今日页打开后优先呈现日期与任务，用户无需越过驾驶舱内容才能打卡。
- 将原今日页顶部的进度、建议、计划轨道、能力摘要与重要日倒计时迁移到独立概览页。
- 长按任务后，在手指触点附近显示悬浮操作菜单，不再立即从底部打开完整编辑页。
- 将“陪陪刷”资料分析题库从当前 72 题扩充为全部 3,988 道去重题目，并保留逐题解析与一题多分类检索。

## 方案比较与选择

### 今日页

1. 增加第 5 个底部 Tab：入口直接，但破坏现有四栏导航和滑动轨道，不采用。
2. 将驾驶舱折叠到任务下方：减少首屏占用，但仍与任务共用长页面，不满足“专门来放”，不采用。
3. 新建 `/overview` 二级页：今日页只保留任务主流程，通过紧凑“概览”入口进入原驾驶舱，采用。

### 长按操作

1. 继续使用底部 Sheet：触控稳定，但与用户要求相反，不采用。
2. 屏幕中央对话框：边界处理简单，但失去任务与操作的空间关联，不采用。
3. 触点锚定悬浮菜单：菜单从长按处出现，自动避让顶部、左右边缘和底部导航，采用。

### 题库

1. 保留 72 题并使用通用规则生成解析：体积小，但不是逐题分析，不采用。
2. 按分类原样导入 4,964 行：实现简单，但 708 道题会重复出现，不采用。
3. 以题目 ID 去重为 3,988 题，同时保存全部分类、原题解析和图片地址，采用。

## 视觉方向

- **Visual thesis**：延续现有轻量、任务导向的像素反馈语言，首页减少卡片堆叠，任务成为首屏唯一主角。
- **Content plan**：今日页负责定日期和完成任务；概览页负责进度、建议、计划与能力；题库页负责搜索、筛选、答题和逐题复盘。
- **Interaction thesis**：长按任务先抬升，再由触点扩出悬浮菜单；完成和删除继续使用现有 PixelGrid 反馈；所有进入、退出仅动画化 `transform` 与 `opacity`。

现有 CSS 变量、浅深主题、考公/通用模式配色保持不变。圆角沿用当前 8 / 12 / 16 / pill 四级尺度；按钮触控区域不小于 44 像素；中文正文保持现有系统字体栈和宽松行高。

## 信息架构

### 今日页 `/`

从上到下：

1. 当前日期、快速新增、排序、任务管理和概览入口。
2. 数据恢复提示，仅在确有恢复状态时显示。
3. 日期轨道。
4. 之前未完成任务。
5. 今日任务。
6. 空状态与快速新增按钮。

今日页不再计算或渲染驾驶舱指标，避免首屏多余工作和视觉延迟。

### 概览页 `/overview`

作为今日 Tab 的二级页，保留底部导航高亮和系统返回行为。页面接收 `date` 查询参数并提供日期轨道，包含：

- 当日完成环；
- 驾驶舱问候与四项指标；
- 下一步建议；
- 计划轨道；
- 能力摘要；
- 重要日倒计时。

### 任务悬浮菜单

`TaskCard` 长按事件改为发出任务与 `clientX/clientY`。父页面持有菜单状态，避免卡片内部直接控制业务操作。菜单提供：

- 编辑任务：关闭菜单后打开现有完整编辑 Sheet；
- 进入专注：跳转计时页并携带任务 ID；
- 调整顺序：进入现有排序模式；
- 删除任务：调用现有自定义确认弹窗和软删除逻辑。

菜单使用全屏透明遮罩承接点空白关闭与 Android 返回键；定位时预留 12 像素视口边距、状态栏安全区和底部导航安全区。首次测量菜单尺寸后再次约束坐标，防止窄屏和横屏溢出。

## 题库数据模型与导入

`AnalysisBankQuestion` 扩展：

- `categories: string[]`：题目所属全部分类；
- `analysis: string`：源库逐题解析；
- `knowledgePoint: string`：知识点；
- `titleImages: string[]`：题干/统计图图片；
- `optionImages: string[][]`：各选项图片。

导入脚本以 `F:/Code-X/Pei-Pei-Shua/app/src/main/assets/bank` 为默认源，也允许通过环境变量覆盖。脚本流式读取 73 MB JSONL，只选“资料分析”12 个模块；按题目 ID 合并分类，并使用资料表补齐材料正文。源库内 3,988 道题全部包含答案和解析，导入后通过测试强制校验。

检索按 `categories` 做多分类匹配，全文索引内容包含题干、材料、来源、知识点、选项和解析。题库复盘优先展示“原题解析”，其后追加所选名师 Skill 的题型识别、最短路径与易错复盘，二者职责不混淆。

## 错误与降级

- 图片加载失败时保留固定比例占位与明确“原题图片暂时无法加载”，不挤压选项布局。
- 没有材料文字但存在题图时，答题页直接显示题图。
- 非题库输入继续使用现有 Skill 通用规则。
- 题库题目若未来缺少逐题解析，完整性测试失败，不静默回退并宣称已分析。
- 菜单定位在无法测量时使用触点右下方的保守坐标，下一帧完成约束。

## 测试范围

### 自动化

- 今日页 DOM 顺序确保日期轨道和任务先于任何概览内容，且 `/overview` 路由存在并归属今日 Tab。
- 长按事件携带坐标；菜单可从遮罩、返回键、编辑、专注、排序和删除路径关闭；四边定位均不溢出。
- 题库总数为 3,988，ID 唯一，12 分类均可检索，答案为有效字母，解析非空，图片数组与选项长度一致。
- 题库题复盘包含源解析，普通文本复盘仍保持原有六段 Skill 输出。

### 渲染与真机

- 320、375、430 像素手机宽度及平板宽度检查首屏任务、菜单四角避让、长标题、数量任务与横屏。
- 两台 ADB 设备验证新增、打卡、长按四项操作、删除确认、排序、概览返回、题库搜索、分类、含图题、答题、原题解析和 Skills 复盘。
- 不卸载、不清数据、不重启，覆盖安装并保留现有记录。
