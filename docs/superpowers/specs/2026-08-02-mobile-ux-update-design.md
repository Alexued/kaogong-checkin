# 考公打卡 v0.4.0 移动端体验升级设计

## 目标

本版本集中完成今日页高频操作、连续日期日历、统一日期选择、统计与设置合并、服务器手动选择、应用内 APK 更新、冷启动动画和中文同步数据修复。Android 是本版本的原生更新目标；网页端保留可用的降级路径。

## 一、今日页结构

今日页采用“进度优先”布局：

1. 顶部显示“今天”或当前选中日期，以及完整日期和星期。
2. 排序和管理使用至少 48px 的图标加文字按钮，放在标题右侧。
3. 标题下方是进度摘要，保留圆形进度和连续打卡天数。
4. 进度摘要下方放连续日期条。
5. 任务列表延续现有卡片和子任务结构。

今日页不再显示离线或未同步横幅。同步状态统一归属设置页的服务器区域。

### 任务长按编辑

- 长按阈值为约 450ms。
- 长按成立时触发轻振动，当前任务卡抬升并显示短暂遮罩。
- 抬升动画结束后直接打开现有 `TaskEditorSheet`，不增加中间菜单。
- 编辑器接收任务及其子任务，保存时保留任务 id 并调用现有更新逻辑。
- 普通点击仍执行打卡或展开子任务。
- 手指移动超过 10px、进入排序模式或开始页面滚动时取消长按。
- 长按完成后抑制紧随其后的 click，避免误打卡。
- 今日任务和结转任务均支持长按编辑。

## 二、连续日期日历

### 收起状态

- 日期条是可横向滚动的连续日期轨道，不再按周或按月瞬间跳转。
- 初次进入时今日位于可视区域正中间，前后各显示三天。
- 横向拖动时日期随手指连续移动，停止后吸附到单日边界。
- 点击日期更新今日页选中日期，并把该日期平滑居中。
- “回到今天”会选择今日并重新居中。

日期轨道预生成足够的前后日期，并在接近边界时扩展范围，避免限定在单个月份。

### 展开与收起

- 在日历区域向下滑超过阈值时展开月历。
- 在展开月历区域向上滑超过阈值时收起。
- 垂直手势优先级只在日历区域内生效，不影响页面正常滚动。
- 展开状态不再用横滑直接切换整月；月份通过明确的上一月、下一月按钮切换。
- 点击月历日期后更新选中日期，并在收起时让该日期居中。

### 完成度颜色

日期条和设置页热力图使用同一套 `completionLevel(date)`：

- 0 级：当天没有完成，或没有计划。
- 1 级：完成比例大于 0 且不超过 25%。
- 2 级：大于 25% 且不超过 50%。
- 3 级：大于 50% 且小于 100%。
- 4 级：当天计划全部完成。

比例只统计主任务，沿用现有统计页排除子任务的规则。颜色继续使用 `--heat-0` 到 `--heat-4`。

## 三、统一日期选择器

新增 `DatePickerSheet`，替换计划结束日、任务截止日和日期跳转中的原生 `input[type=date]`。

- 使用底部面板，不跳离当前上下文。
- 显示月份标题、上一月/下一月、星期标题和完整月历。
- 支持“今天”“一周后”“清除”快捷操作。
- `allowClear=false` 时隐藏清除操作。
- 点击确认才写回值；点击遮罩或取消不修改原值。
- 今日页日期标题可打开该面板并跳转日期。
- 日期面板通过 Teleport 放到 body，避免 ViewPager transform 影响 fixed 定位。

## 四、设置与统计合并

设置页顶部加入学习概览：

- 连续打卡天数。
- 主任务总完成数。
- 计时总时长。
- 背诵总题数。
- 近 30 天完成度热力图。

热力格可点击进入现有日期详情页。底栏移除“统计”，保留“今日 / 计时 / 背诵 / 设置”四项。`/stats` 保留兼容路由并重定向 `/settings`；`/stats/day/:date` 继续作为二级页。

`TAB_PATHS`、常驻 ViewPager 页面和底栏配置同步改为四项，避免索引不一致。

## 五、服务器扫描与同步状态

### 扫描模型

重构 UDP 自动发现为候选服务器扫描：

- 进入设置页且同步开启时自动开始扫描。
- 扫描期间持续收集广播，不在发现第一台服务器后自动连接。
- 候选项按 `host:httpPort` 去重，记录服务器名、地址和最近发现时间。
- 用户点击候选项后才保存服务器地址并重启同步。
- 保留手动输入地址和“重新扫描”。
- 关闭同步时停止 UDP socket 和监听器。

已有服务器地址继续用于应用启动连接，但扫描结果不会自动覆盖它。

### 状态归属

设置页服务器区域显示：

- 同步开关。
- 当前连接状态和选中服务器。
- 未同步队列条数。
- 扫描状态及候选服务器。
- 手动地址和“用本地覆盖服务器”。

同步模块将队列长度同步到 Pinia 的 `pendingSyncCount`，使 UI 能响应入队、发送和覆盖清空。

## 六、应用内 APK 更新

### Android 原生插件

新增项目内 Capacitor Android 插件 `AppUpdatePlugin`，封装系统 `DownloadManager`：

- `startDownload({ url, fileName })` 开始下载并返回 download id。
- 插件定时查询总字节数、已下载字节数和状态。
- 通过 `downloadProgress` 事件发送 `percent`、`bytesDownloaded`、`totalBytes` 和近似速度。
- 下载保存到应用专属 external files downloads 目录。
- 下载完成后通过现有 `FileProvider` 获取 content URI。
- `installDownloadedApk()` 打开 Android 系统安装确认页。
- 如果本应用没有“安装未知应用”权限，先打开该应用的授权设置页。
- 取消、失败和重复下载均返回明确状态，不复用损坏文件。

Manifest 增加 `REQUEST_INSTALL_PACKAGES`，`file_paths.xml` 增加 external-files-path。下载仍可能显示 Android 系统通知，但不会打开浏览器。

### 更新界面

设置页版本区域维护 `idle / checking / available / downloading / downloaded / installing / error` 状态。

- 下载中同时显示圆形百分比和线性进度条。
- 显示百分数、已下载/总大小和速度。
- 下载完成后按钮变为“安装更新”。
- 失败后保留可读错误并允许重试。
- 网页端使用普通链接下载作为降级，不伪装原生安装能力。

## 七、短启动动画

采用“极短品牌闪现 + 桌面跃入”：

- 品牌图标约 180ms 淡入。
- 今日页从约 94% 缩放、轻微模糊和低透明度过渡到正常状态，约 360ms。
- 总时长控制在约 540ms，不设置额外停留时间。
- 仅 WebView 冷启动时播放；同一进程内普通前后台切换不重复播放。
- 使用 `sessionStorage` 标记本次 WebView 会话是否已播放。
- 设置页提供“启动动画”开关，保存在设备本地 `localStorage`，不参与服务器同步。
- 系统启用 reduced motion 时跳过缩放和模糊，只做极短淡入。

启动覆盖层 Teleport 到 body，并在结束后彻底卸载，不能阻挡页面触摸。

## 八、中文乱码修复

### 已确认原因

服务器当前只有计时记录 `aef0f3d3-32e9-49d2-8064-919d5db320af` 的 label 为 `????`。未改动源目录中同一记录为“测试计时”。该损坏由先前 Windows PowerShell 覆盖接口测试提交字符串时的错误编码产生，之后被服务器快照同步到移动端；现有浏览器 `fetch` JSON 路径本身使用 UTF-8。

### 修复措施

- 从未改动源目录按记录 id 恢复该 label，不修改其他用户数据或时间戳。
- 服务端 JSON 响应明确声明 UTF-8。
- 覆盖接口继续接收 `application/json`，拒绝错误结构后不写盘。
- 增加 Node 端 UTF-8 往返测试，使用包含中文任务、子任务、计时和设置的完整状态。
- 测试覆盖后读取服务器原始 UTF-8 字节并比对字符串，禁止再用 Windows PowerShell 默认字符串编码提交生产数据。
- 真机清理连接后重新拉取服务器快照，确认“测试计时”和新增中文数据均正常。

## 九、错误处理

- 长按被滚动取消时不得打开编辑器或触发打卡。
- 日期手势方向不明确时不处理，交给页面滚动。
- 扫描失败不清除已选服务器或手动地址。
- 切换服务器前保留本地队列；连接后按既有规则先拉服务器，再重放本地变更。
- 下载进度无法取得总大小时显示已下载大小和不定进度，不显示错误百分比。
- APK 下载失败或安装权限未授予时不删除本地学习数据。
- 启动动画异常时立即卸载覆盖层，应用必须可操作。

- Playwright 验证 360x800、412x915、768x1024 视口无横向溢出。

### 真机验证

- ADB 安装覆盖现有版本，确认应用数据保留。
- 长按今日任务进入编辑并保存中文标题。
