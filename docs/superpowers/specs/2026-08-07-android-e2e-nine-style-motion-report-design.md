# Android 真机验收、九风格独立动效与网页版报告设计

## 背景与目标

本阶段同时交付三件事：

1. 在已连接的 Android 真机上，对 `com.wjy.kaogong` 的主要业务、同步开关、局域网更新和生命周期行为做完整验收。
2. 为 Apple 之外的九套介绍页补齐与各自布局、材质和叙事一致的连续过渡动画，而不是复用同一套淡入或只更换配色。
3. 生成可公开访问、可追溯且已脱敏的网页版测试报告，并从产品页与 README 提供入口。

当前真机安装版本为 `0.6.0`（versionCode 8），待测 APK 为 `0.7.1`（versionCode 10）。两者使用相同签名证书。用户已明确授权测试期间新增、修改和删除数据，但仍采用先备份、后覆盖升级、只删除隔离测试数据的保护策略。

## 已选总体方案

### 动效：共享场景状态机 + 九页本地编舞

新增零依赖共享控制器，负责：

- 使用单个 `IntersectionObserver` 维护章节的 `is-prev`、`is-current`、`is-next` 和进入状态。
- 记录滚动方向、风格切换方向和前进/后退恢复状态。
- 为快速滚动、页面缓存恢复、窗口尺寸变化和 `prefers-reduced-motion` 提供统一生命周期。
- 只输出语义状态，不输出统一视觉动画。

九套页面在自己的 CSS 和现有交互脚本中将共享状态翻译成完全不同的运动语言。这样能保证上一段、当前段和下一段连续衔接，同时避免九页变成同一模板。

未选方案：

- 九页完全独立导演：自由度最高，但会重复九套观察器、恢复、降级和清理逻辑，长期一致性风险高。
- GSAP + ScrollTrigger：时间轴控制力强，但会增加依赖、移动端滚动和 pin 风险，不符合当前零依赖静态 Pages 架构。

### 真机：保留数据的覆盖升级 + 隔离测试数据

测试前通过 `run-as com.wjy.kaogong` 备份私有数据并记录文件哈希、实体计数和偏好基线。覆盖安装使用 `adb install -r`，禁止 `pm clear` 和卸载。测试数据统一使用 `KG-QA` 前缀，并只删除这些隔离实体。

涉及真实数据的验证只比较数量、ID 哈希和偏好摘要，不在公开报告中展示正文。覆盖升级后必须先证明基线数据仍在，再执行写操作。

### 报告：版本 + 运行 ID 的不可变静态报告

每次真机验收写入独立目录：

`docs/reports/v0.7.1/adb-<run-id>/`

同时维护报告目录：

`docs/reports/index.html`

版本化报告不被后续运行覆盖，避免 GitHub Pages 约十分钟缓存造成历史报告内容漂移。每份报告同时包含人类可读 `index.html`、机器可读 `report.json` 和证据哈希清单。

## 九套独立运动语言

### 1. 古风长卷

- 章节像纸幅沿阅读方向舒展，墨线先延展，标题和正文后落位。
- 任务完成反馈使用克制的朱记落印，不使用弹跳。
- 背诵卡保留翻面，但进入和退出与纸层前后关系一致。
- 跨页遮罩表现为纸幕收卷。

### 2. 赛博朋克

- 横向扫描、短促切片和坐标锁定组成主要节奏。
- 雷达只在用户主动扫描时旋转，节点按遥测顺序点亮。
- 模块切换必须先撤离旧层，再让新层对位，避免 `max-height` 布局动画。
- 跨页使用横向扫描幕，不做普通交叉淡化。

### 3. 终端控制台

- 提示符先出现，输出行通过遮罩逐行显现，不使用逐字定时器。
- 旧输出向上退出，新输出从提示符下方进入。
- 命令面板、同步状态和复制反馈都有可逆的进入/退出状态。
- 跨页表现为终端清屏和新会话建立。

### 4. 政府严肃型

- 标题、文号、表格、正文按公文阅读顺序稳定落位。
- 双线、分隔线和表格线从左向右展开。
- 复制完成使用克制的盖章反馈，不弹跳、不闪烁。
- 跨页表现为文件页纵向交接。

### 5. 冲刺仪表

- 分道线先建立，计分与目标短促冲线归位。
- 上一赛段向上退出，下一赛段从下方接棒。
- 任务完成条带扫过，计数只在进入当前章节时递进一次。
- 跨页沿赛道方向横向推进。

### 6. 包豪斯

- 红、黄、蓝几何块沿正交网格从不同方向归位。
- 任务点击从偏移态吸附到网格，不做漂浮或无语义旋转。
- 章节前后关系由块面位置和遮挡关系表达。
- 跨页使用分色几何块依次覆盖和拆解。

### 7. 日系文具

- 页签压下，纸页沿装订边轻抬并平移换页。
- 勾选笔划显现，便签根据前进/后退方向从纸堆切换。
- 不使用大幅缩放，保持轻、短、安静的触感。
- 跨页表现为纸张抬起和落下。

### 8. 科研蓝图

- 尺寸线、连接线先绘制，标注与组件随后正交装配。
- 更新检测流程沿 `01 -> 04` 逐级点亮。
- 标注内容交叉切换，不瞬时替换。
- 跨页由绘图仪网格扫描完成。

### 9. 墨水报刊

- 栏线先展开，标题、导语和侧栏按阅读顺序排印。
- 重点方框使用短促填墨，答案通过版面下推展开。
- 不让隐藏内容瞬时改变布局。
- 跨页表现为报纸版面纵向送纸。

## 动效时间语言

- 直接控件反馈：`160ms` 至 `220ms`，使用清晰的 ease-out。
- 材料与局部组件：`420ms` 至 `560ms`。
- 章节进入与前后交接：`640ms` 至 `760ms`，基准曲线 `cubic-bezier(.22, 1, .36, 1)`。
- 章内错峰：`35ms` 至 `90ms`，由各风格密度决定。
- 高频路径仅动画 `transform`、`opacity` 和合成友好的 `clip-path`；不在滚动中动画 `height`、`top`、`left`、阴影或滤镜。
- 不使用滚动锁定、长距离 pin、无限循环或自动播放装饰动画。

## 共享状态与失效安全

HTML 默认完整可见。只有共享控制器成功初始化后才给根节点添加 `motion-ready`。CSS 只允许在 `.motion-ready` 下设置等待进入的隐藏状态。

这会修复当前风险：页面内联脚本先添加 `.js`，但共享延迟脚本加载失败时，`data-enter` 内容会永久保持透明。

共享控制器负责：

- `[data-motion-scene]` 的前一章、当前章和下一章状态。
- `[data-reveal]` 的首次进入和可选的可逆进入。
- `data-motion-direction="forward|backward"`。
- 页面从 bfcache 恢复时重新计算状态。
- 不支持 `IntersectionObserver` 或减少动态时立即显示全部内容。

风格切换器记录源/目标序号和方向。支持跨文档 View Transition 时固定切换器并调用每页材质遮罩；不支持时保留目标底色覆盖，避免白屏。快速连续点击只接受第一个有效切换请求。

## 减少动态与无 JavaScript

- `prefers-reduced-motion: reduce` 下取消空间位移、裁切、错峰和循环，仅保留 `80ms` 至 `120ms` 的必要状态淡化。
- 显式关闭 `::view-transition-old/new(root)` 的默认长动画。
- 关闭 JavaScript 时，正文、下载链接、展开内容和关键答案必须可读。
- 局部交互若依赖 JavaScript，静态状态至少展示一个完整可理解的示例。

## 真机测试范围

### 升级与数据

- 记录 `0.6.0` 数据和偏好基线，验证备份可读取并生成 SHA-256。
- 同签名 `adb install -r` 覆盖升级到 `0.7.1`。
- 比较升级前后核心实体计数、ID 哈希、主题和启动动画偏好。

### 主流程

- 冷启动、热启动、后台恢复、Android 返回键和二级页面返回。
- 四个根 Tab 点按与左右手势，快甩、慢拖、边界回弹和纵向滚动冲突。
- 今日任务、日历、补卡、子任务、排序、完成庆祝和日详情。
- 任务新增、编辑、归档、恢复和 `KG-QA` 隔离任务删除。
- 正计时、倒计时、打点、保存/丢弃、历史和隔离记录删除。
- 百化分、公式、翻面、自评、错题和隔离历史清理。
- 计划截止日期、主题、启动动画、总览热力图和共享过渡。

### 同步与更新

- 验证升级用户的同步迁移默认值。
- 关闭同步后停止 REST、WebSocket、UDP、重连和 LAN 更新检查，本地写入仍持久化。
- 重启后保持关闭；重新开启后发现电脑、配对、补传并接收回流。
- 在 `0.6.0` 阶段验证发现和下载 `0.7.1` 的基础更新链路。
- 对 `0.7.1` 的取消/重试边界使用受控的高版本 LAN 测试元数据；不发布虚假正式版本。

### 生命周期与兼容

- 断网、电脑服务退出/重启、横竖屏、软键盘、锁屏和进程重启。
- 检查 logcat 中的 FATAL、ANR，检查 `dumpsys gfxinfo` 的卡顿摘要。
- 检查更新下载残留和本地状态完整性。

## 证据与隐私

公开报告允许展示：机型营销名、Android/API、分辨率、密度、ABI、App 版本、测试时间、结果和脱敏截图。

公开报告不得展示：

- ADB serial、IMEI、Android ID、MAC、IP、SSID。
- 配对码、token、电脑用户名和绝对路径。
- 真实任务、打卡、通知正文和完整 logcat。

设备统一称为 `Device A`。日志中的地址和凭证替换为 `<LAN_IP>`、`<TOKEN>`。截图只使用 `KG-QA` 数据并检查状态栏和通知。

## 网页报告结构

- 总览：通过、失败、阻塞、耗时和总体结论。
- 构建身份：版本、versionCode、包名、APK SHA-256、Git commit、运行 ID。
- 设备环境：脱敏设备信息。
- 用例表：固定 ID、步骤、预期、实际、状态、耗时和证据链接。
- 自动化与构建：Web、server、desktop、Android 单元测试结果。
- 性能与稳定性：console、logcat、ANR、gfxinfo 和动画 QA。
- 已知限制与未覆盖项：明确区分失败和外部条件阻塞。
- `report.json`：与页面同源的机器可读数据。
- `evidence-manifest.json`：证据文件 SHA-256。

## 验收标准

- `0.6.0 -> 0.7.1` 覆盖升级后既有数据与偏好可证明保留。
- 核心业务、同步总开关和更新流程在真机上有逐项结果与脱敏证据。
- 九个非 Apple 页面分别拥有首屏、章节、核心交互和跨页四类独立动画。
- 上一章、当前章、下一章在双向滚动时连续、唯一且可逆。
- 桌面与移动端无横向溢出、内容重叠、跳动或滚动劫持。
- 正常、减少动态和无 JavaScript 三种模式内容均可访问。
- 线上 Pages、报告目录、版本化报告和 README 入口均可访问。
- 报告不泄露设备标识、网络信息、凭证或真实学习数据。
