# v0.5 动效与倒计时设计

## 目标

建立一致、可感知且不拖慢操作的动效语言，并为计时页增加完整倒计时能力。所有动效只使用 `transform` 与 `opacity` 作为主要动画属性，支持 `prefers-reduced-motion`。

## 动效语言

- 直接反馈：140-180ms，轻微缩放，使用 crisp easing。
- 页面切换：280-340ms，跟手位移叠加 2%-4% 缩放与透明度层次。
- 场景进入：360-440ms，使用 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 串行动画：任务卡抬升 220ms，稳定后打开编辑层；遮罩建立后再释放卡片。

## 页面左右切换

保留现有 ViewPager 跟手轨道。每个页面增加独立内容层，根据页面距离当前视口的比例计算透明度、缩放和 22px 以内的反向位移。拖动时无 transition，直接跟手；松手或点击底栏时统一使用页面 transition。

## 启动衔接

启动图播放期间主界面保持预备状态。启动图退出后，主内容从 0.92 倍、18px 下移和轻微模糊进入，底栏稍后上移进入。关闭启动动画时直接显示，不额外延迟。

## 任务长按编辑

长按 450ms 后任务卡进入抬升态，220ms 完成放大。随后才挂载编辑面板；遮罩先淡入，面板延迟 40ms 上滑。卡片在遮罩覆盖后恢复，避免放大恢复与编辑面板同时运动。

## 倒计时

- 计时页左上使用“计时 / 倒计时”分段控件。
- 倒计时空闲时可输入分钟和秒，并提供 5、15、25 分钟快捷值。
- 支持开始、暂停、继续、提前结束和完成后保存/丢弃。
- 倒计时运行时显示圆形剩余进度，归零时触发一次完成脉冲与短震动，再打开保存面板。
- 记录增加可选 `mode` 字段；旧记录默认按普通计时处理。

## 学习概览详情

点击热力格时用 View Transitions 将格子放大为日期详情页；返回时详情页缩回原日期格。缺少 View Transitions 的环境使用 300ms 缩放淡入淡出降级方案。日期详情提供明确的“返回概览”入口。

## 验证

- 360x800、412x915、768x1024 页面与动画截图。
- 快速连续左右滑动、点击底栏切换、启动动画开关、减少动态效果。
- 长按顺序、编辑面板退出、日期详情进入/返回。
- 倒计时开始、暂停、继续、归零、提前结束、保存与旧计时记录兼容。
- Web 构建、TypeScript、服务器测试、Android APK 编译与签名验证。
