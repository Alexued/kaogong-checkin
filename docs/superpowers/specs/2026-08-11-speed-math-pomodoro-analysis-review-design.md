# 速算、番茄钟与资料分析复盘设计

## 目标

在不增加底部导航复杂度的前提下，为考公模式补齐三项高频能力：专项速算、番茄专注、资料分析题目讲解与复盘。新增记录继续参与本地持久化、电脑同步和设备直连完整替换。

## 信息架构

- 背诵页：`百化分 / 公式 / 速算 / 题目复盘`。
- 计时页：`计时 / 倒计时 / 番茄钟`。
- 通用模式保持原有行为；上述训练模块只在考公模式出现。

## 速算

- 分类采用参考图中的“基础速算”和“资料分析填空”。
- 配置包含分类、难度、题量；题量预设 5/10/15/20/25。
- 每题记录分类、题干、标准答案、用户答案、正确性和用时。
- 作答正确使用 PixelGrid 扩散反馈，错误使用 PixelGrid 收束反馈；结束页展示正确率、平均用时和错题。
- 题目生成与判分完全离线，数值题按题型使用合理精度与容差。

## 番茄钟

- 默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟、4 个专注轮次后长休息。
- 运行态以绝对时间戳计算，页面进入后台后恢复时不会因动画帧暂停而漂移。
- 每个完成的专注阶段自动写入计时历史，模式标记为 `pomodoro`，可关联任务。
- 阶段完成后显示 PixelGrid，并由用户开始下一阶段，避免自动播放造成打扰。

## 资料分析题目复盘

- 输入来源：拍照、相册、手动输入。
- Android 使用打包在应用内的 ML Kit 中文文本识别；Web 端保留图片预览和手动输入降级。
- 图片不写入同步状态，仅保存识别/编辑后的题目文本和结构化复盘。
- 离线规则引擎基于陈怀安讲义的主线：`现期 = 基期 × (1+r)`，以及数学思维、选项思维、区间思维。
- 输出固定为：题型识别、找数检查、核心关系、最短路径、估算策略、易错复盘；根据题目关键词匹配基期、增长量、增长率、比重、平均数、倍数、混合增长、年均增长、拉动/贡献等规则。

## 数据与同步

- UI 状态新增 `speedDrills`、`analysisReviews` 两个集合。
- v3 领域状态新增对应集合，计时模式扩展 `pomodoro`。
- 旧数据缺少新集合时自动补空数组；新增集合使用原有 LWW 软删除规则。
- 服务器 v2 状态仍保持版本号 2，但显式保存和同步新增集合；设备直连 v3 快照完整包含新增记录。

## 测试

- 单元测试：题目生成、答案容差、讲题规则匹配、状态迁移、番茄阶段判定。
- 构建测试：Web、Node 服务、Android Debug/Release。
- 真机测试：入口、全部分类可开始、作答流程、历史、OCR 拍照/相册、手动输入、前后台番茄恢复、阶段完成自动记录、删除与同步快照。
