# GitHub Pages 苹果官网独立页面设计

## 目标与范围

本阶段只重做 GitHub Pages 根入口，交付一套完整的「苹果官网」产品介绍页，作为后续九套独立页面的质量样板。

根入口必须做到：

1. 第一视口明确展示产品名「考公打卡」、核心价值和 `v0.5.1` APK 直接下载。
2. 不展示应用截图。所有任务、计时、背诵和同步界面均由 HTML/CSS 原生绘制。
3. 页面不是现有共享 DOM 的换色版本，而是独立的信息结构、布局、交互和动效。
4. 提供任务勾选、计时器、背诵卡翻面和局域网扫描四项产品轻交互；校验值复制作为下载区工具行为。
5. 保持静态、零依赖、可由 GitHub Pages 直接托管。

其余九套风格不在本阶段实现。页面不提供指向未完成页面的入口；待第二套页面完成后，再加入跨页面风格导航。

## 已选架构

最终十套页面采用「独立页面 + 共享事实与基础行为」架构：

- 根路径 `/kaogong-checkin/` 是苹果官网作品。
- 后续页面使用 `/kaogong-checkin/styles/<style>/` 路径。
- 每套拥有独立 HTML 结构、布局 CSS 和交互模块。
- APK 地址、版本、大小、SHA-256、无障碍规则和跨文档过渡约定保持一致。
- 支持的浏览器通过跨文档 View Transition 切换；不支持时正常导航。

本阶段继续使用根目录的 `index.html`、`styles.css` 和 `app.js`，但它们将变为苹果页面专用文件。旧的 `themes.css` 不再参与根页面。

## 页面叙事

### 1. 全局导航

导航是高度固定的纯色条，包含产品名、GitHub 源码链接和 APK 下载命令。导航不使用玻璃拟态、渐变或悬浮卡片。移动端保留产品名和下载，源码链接移动到页脚。

### 2. 首屏：今天，现在开始

- H1 为「考公打卡」，支持文案为「今天的计划，现在开始执行」。
- 下载按钮、版本号、大小和 Android 版本要求在第一视口内可见。
- 主视觉是一台由 HTML/CSS 绘制的手机，屏幕显示当天任务与完成进度。
- 手机不是截图容器；每一项文字、进度条、按钮和状态都是真实 DOM。
- 首屏高度在桌面与移动端都露出下一章节提示，不做全屏封闭英雄区。

### 3. 今日计划：先把今天看清

白色内容带使用大字号完成率、任务明细和原生手机界面形成不对称构图。用户可勾选三个示例任务，完成数量和进度条即时更新。交互仅保存在当前页面内，刷新后恢复初始状态。

### 4. 专注计时：让时间真正开始

黑色全宽内容带以大号 `25:00` 为视觉中心，配合一个精简计时控制器。用户可开始、暂停和复位倒计时。计时状态通过按钮文本、`aria-pressed` 和实时区域同步表达，不依赖颜色判断。

### 5. 背诵训练：记住，再检验

冷灰内容带以问题、答案和熟练度状态组成原生背诵卡。用户可翻面查看答案，再切换到下一题。翻面动画使用受控的三维旋转；减弱动效模式下直接切换内容。

### 6. 本地同步：数据留在自己手里

白色内容带使用手机、电脑和局域网路径组成原生数据流示意。用户可点击「扫描局域网」，状态依次显示「正在扫描」「已发现」「已连接」，连接路径只播放一次。文字明确离线保存和局域网同步，不暗示云服务。

### 7. 下载终章

黑色全宽终章前置展示：

- 版本：`v0.5.1`
- 文件名：`kaogong-checkin-v0.5.1.apk`
- 文件大小：`4,383,386` 字节（页面显示 `4.18 MiB`）
- 平台：Android 7+
- SHA-256：`C39DA4AA47DD6989CA0A571B913BD2D06D30751C19CE845F61B69FC582E18EA9`
- APK：
  `https://github.com/Alexued/kaogong-checkin/releases/download/v0.5.1/kaogong-checkin-v0.5.1.apk`

下载按钮是本节唯一主操作。复制校验值按钮维持固定尺寸，成功或失败状态不造成布局跳动。

## 视觉语言

- 基础色为冷白、纯黑、石墨灰和产品蓝，暖绿色只用于完成状态。
- 不使用渐变、玻璃拟态、光球、噪点纹理、嵌套卡片或装饰性 SVG 插画。
- 标题采用系统无衬线字体，中文优先使用 `PingFang SC`、`Microsoft YaHei` 回退。
- 英文数据和计时数字使用系统等宽字体回退。
- 大字号只用于章节标题和关键数字；紧凑控件使用正常界面字号。
- 手机和交互面板属于真实框定工具，可使用小圆角；页面章节本身保持无卡片、全宽分带。

## 动效系统

动效参考 iPhone 产品介绍页的克制节奏，不复制其素材或滚动劫持：

- 页面载入：标题与下载操作在 `520ms` 内淡入，手机舞台在 `760ms` 内上移 `24px` 并归位。
- 章节进入：最大位移 `24px`，持续 `640ms`，使用 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 同组内容按 `55ms` 错峰，总错峰不超过 `220ms`。
- 手机舞台只使用 `transform` 与 `opacity` 做轻微缩放和层次变化。
- 按钮悬停上移不超过 `2px`，按下缩放到 `0.98`。
- 计时数字不做逐字符动画，避免宽度抖动。
- 不拦截滚轮，不强制翻页，不把移动端内容固定在粘性场景中。

`prefers-reduced-motion: reduce` 下关闭滚动揭示、空间变换、卡片翻转和平滑滚动；全部内容立即可见，交互状态仍正确更新。

## 响应式与无障碍

- 重点验证宽度：`320`、`360`、`390`、`412`、`768`、`1024`、`1440`。
- 第一视口在全部目标尺寸中显示 H1 和直接下载入口，并露出后续内容。
- 桌面端章节可使用局部粘性舞台；`768px` 以下改为自然文档流。
- 所有按钮和复选目标最小尺寸为 `44px`。
- 键盘可完成任务勾选、计时、翻卡、下载和校验值复制。
- 焦点样式清晰；颜色不是唯一状态提示。
- SHA-256 和文件名允许断行，不产生横向滚动。
- 无 JavaScript 时仍显示完整产品介绍、静态渲染界面、APK 链接和校验值。

## JavaScript 边界

JavaScript 只负责：

1. IntersectionObserver 章节揭示及无支持降级。
2. 当前页面内的任务完成率更新。
3. 计时器开始、暂停和复位。
4. 背诵卡翻面与换题。
5. 局域网扫描模拟状态。
6. SHA-256 复制状态。
7. 低频滚动进度更新，统一通过 `requestAnimationFrame` 调度。

不引入框架、动画库、外部字体、统计脚本、Cookie 或网络请求。

## 错误与降级

- Clipboard API 不可用时显示「请手动复制」，校验值始终可选择。
- IntersectionObserver 不可用时全部章节立即显示。
- JavaScript 禁用时，任务与计时器保持静态样例，下载不受影响。
- 页面后台运行时，计时器根据时间戳计算剩余时间，避免定时器节流造成明显漂移。
- 交互脚本只查询存在的元素，单一增强功能失败不应阻断其他功能。

## 验证清单

1. HTML 结构、JavaScript 语法、`git diff --check`。
2. 桌面和移动目标视口截图对比。
3. 横向溢出、文本换行、首屏下载可见性和下一章节露出。
4. 鼠标、键盘和触摸交互。
5. 任务完成率、计时器时间戳、翻卡、局域网扫描和复制状态。
6. 正常动效与 `prefers-reduced-motion`。
7. JavaScript 禁用和 IntersectionObserver 缺失路径。
8. 控制台错误、失败请求、404 和资源 MIME 类型。
9. 快速滚动、窗口缩放和后台切换后的计时准确性。
10. APK 地址、文件大小和 SHA-256 与 `v0.5.1` Release 一致。

## 验收标准

- 页面第一眼是完整的苹果产品叙事，而不是旧页面换色。
- 页面不加载或显示四张旧应用截图。
- 每个章节有不同的构图与信息节奏，且所有界面由 DOM 原生渲染。
- 四项轻交互可用、可键盘操作，并具有明确状态反馈。
- 正常滚动具有连续的产品舞台感，移动端无卡顿或滚动劫持。
- 所有目标视口无重叠、截断或横向溢出。
- 无 JavaScript和减弱动效路径仍可阅读并下载。
- 本地预览完成桌面、移动、控制台和网络检查后在默认浏览器打开。
