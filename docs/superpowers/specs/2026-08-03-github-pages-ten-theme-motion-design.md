# GitHub Pages 十主题与丝滑动效设计

## 目标

在现有「考公打卡」GitHub Pages 下载页基础上，提供 10 套可即时切换的完整视觉风格，同时保持同一份真实内容、同一组应用截图、同一个 APK 下载地址和一致的无障碍体验。

页面必须满足两个核心结果：

1. 用户在首屏即可识别产品并直接下载 `v0.5.1` APK。
2. 切换主题与滚动浏览的观感接近 iPhone 产品介绍页，节奏流畅、画面稳定，但不劫持滚动、不牺牲移动端性能。

## 已选架构

评估过三种实现方式：

1. **十份独立页面**：每套风格自由度最高，但内容、下载信息和无障碍修复需要同步十次，切换时还会整页刷新。
2. **单页面纯换色**：维护成本最低，但十套风格只会成为配色变体，无法满足「古风、终端、政府」等明显不同的视觉语法。
3. **单语义文档加十套皮肤与布局变体**：共享内容和行为，以 `data-theme` 驱动色彩、字体、边框、构图和装饰层。这是最终采用的方案。

所有主题共享一份 HTML 语义结构。CSS 负责视觉系统和响应式构图，JavaScript 只负责主题状态、原生 View Transition、滚动章节状态、进度条与校验值复制。

## 十套主题

### 01 古风·策论长卷

- 主色：宣纸白、墨黑、石青、朱红。
- 字体：中文标题使用楷体与宋体回退，正文使用可读的系统宋体。
- 构图：竖向卷轴分栏、细墨线、题签式章节索引，真实截图保持彩色且可辨认。
- 标志动作：章节题签像展开的纸页一样从窄幅展开，位移很小，不模拟物理卷轴。

### 02 赛博朋克·夜行考场

- 主色：碳黑、冷白、电青、品红、警示黄。
- 字体：粗窄无衬线搭配等宽数据字体。
- 构图：不对称信息框、硬直角切角、坐标与扫描编号，不使用渐变或霓虹光晕。
- 标志动作：切换时界面以短促的横向裁切和对位完成，不加入无限闪烁。

### 03 苹果产品页·纯净聚焦

- 主色：纯黑、冷白、石墨灰、产品蓝、少量暖橙。
- 字体：系统无衬线，标题宽松、正文克制。
- 构图：大留白、居中产品舞台、极少分隔线，重点由真实手机截图承担。
- 标志动作：截图在滚动中以轻微缩放、景深层次与交叉淡化完成章节接力。

### 04 终端炫酷·执行控制台

- 主色：终端黑、磷光绿、琥珀黄、冷灰、错误红。
- 字体：Cascadia Mono、Consolas 与中文系统等宽回退。
- 构图：命令提示符、日志行号、ASCII 风格边框和状态栏，下载按钮呈现为可执行命令。
- 标志动作：标题逐段显现，使用遮罩而非逐字符定时器，避免抖动和无意义等待。

### 05 政府严肃·公文信息台

- 主色：正式红、纸白、墨黑、深灰、辅助金。
- 字体：中文宋体标题与系统黑体正文。
- 构图：公文式层级、严格网格、双线分隔、版本与校验信息前置。
- 边界：不使用国徽、印章、机关名称或任何政府背书暗示。
- 标志动作：内容按正式文件阅读顺序稳定显现，不使用炫光和弹跳。

### 06 冲刺仪表·专注执行

- 保留当前未提交的高冲击原型作为第六套主题。
- 主色：石墨黑、冷白、信号黄、薄荷绿、珊瑚红。
- 构图：计时器读数、硬分隔、超大编号和运动海报式节奏。
- 标志动作：数字与规则线先建立画面，内容随后按短间隔进入。

### 07 包豪斯海报·结构训练

- 主色：纸白、炭黑、正红、钴蓝、明黄。
- 字体：几何无衬线与粗体中文黑体。
- 构图：非对称块面、正交线条、不同宽度的内容轨道，不使用装饰圆球。
- 标志动作：块面沿网格短距离滑入并精确归位。

### 08 日系文具·每日手账

- 主色：清白、铅笔灰、群青、番茄红、薄荷绿。
- 字体：清晰的系统圆体回退搭配细黑体。
- 构图：日期页签、横线、复选标记、页码和装订边距，避免奶油色主导。
- 标志动作：页签与勾选状态分层出现，截图保持稳定不倾斜。

### 09 科研蓝图·学习实验室

- 主色：工程白、钴蓝、深墨、信号橙、荧光绿。
- 字体：工程无衬线与等宽标注字体。
- 构图：尺寸标注、坐标、模块剖面与数据编号，以白底为主避免整页深蓝。
- 标志动作：测量线先延展，内容随后显现；只动画 `transform`、`opacity` 与受控裁切。

### 10 墨水报刊·备考日报

- 主色：新闻纸白、浓墨黑、冷灰、报刊红、编辑蓝。
- 字体：高对比中文宋体标题、紧凑黑体正文、等宽数据。
- 构图：头版标题、栏线、导语、日期与版本号，章节结构像专栏而不是卡片网格。
- 标志动作：栏目按阅读顺序交叉淡入，避免仿旧噪点遮挡截图。

## 主题选择器

- 页眉下方放置可横向滚动的十项风格轨道，桌面端完整显示，窄屏保持稳定高度。
- 每个项目包含两位编号、风格名称和颜色样本，当前项有明确的形状、颜色与 `aria-checked` 状态。
- 控件使用 `radiogroup` 语义，支持点击、Tab、方向键、Home 和 End。
- 默认主题为当前「冲刺仪表」。用户选择写入 `localStorage`，下次访问在首帧前恢复。
- 每次切换同步更新 `<meta name="theme-color">`。
- 页面内容、滚动位置、下载链接和章节状态在切换时保持不变。

## 页面结构

### 首屏

- 紧凑页眉保留品牌、GitHub 与下载入口。
- 首屏使用真实倒计时截图作为主要产品信号，而不是抽象插画。
- 产品名 `考公打卡` 是唯一 H1，直接 APK 下载在所有目标视口的首屏内可见。
- 首屏底部露出下一段内容，提示页面可继续滚动。

### 能力摘要

每日计划、专注计时、背诵训练和本地同步以一条无卡片信息带呈现。主题可改变编号、线条与排版方式，但不能改变信息顺序。

### 产品叙事

- 桌面端采用 Apple 产品页式双轨结构：文字章节自然滚动，产品截图舞台在限定区间内粘性停留。
- 四个章节进入焦点时，截图以交叉淡化、轻微缩放和裁切变化切换。
- 不锁定滚轮、不改变滚动距离、不做全屏强制翻页。
- 移动端关闭粘性舞台，每个章节按「标题、说明、截图」自然堆叠。
- 无 JavaScript 时直接显示四张完整截图，不依赖动画才能阅读。

### 下载终章

最终下载区包含 APK 文件名、版本、体积、平台、Release 链接和 SHA-256。复制按钮的成功与失败状态使用固定尺寸，不造成布局跳动。

## 动效语言

### 主题切换

- 支持的浏览器使用 `document.startViewTransition()`。
- 旧主题在 180 ms 内淡出并轻微缩至 `0.995`，新主题用 `cubic-bezier(0.22, 1, 0.36, 1)` 在 520 ms 内进入。
- 产品截图只做极轻的尺度校正，文字、边框和背景共同完成材质变换。
- 不支持 View Transition 时使用 160 ms 的透明度降级，不出现白屏。
- 快速连续点击时以最后一次选择为准，不堆积动画队列。

### 首屏与章节

- 首屏采用 60 ms 到 80 ms 的层级错峰，总时长控制在 700 ms 内。
- 章节进入用 16 px 到 24 px 位移、透明度和裁切完成，总时长 560 ms 到 760 ms。
- 粘性舞台的截图切换使用 420 ms 到 620 ms 的交叉淡化，前景与背景的速度差不超过 8%。
- 下载按钮只在悬停时上移 2 px，按下缩放至 `0.97`，不使用循环脉冲。

### 性能边界

- 滚动事件只安排一次 `requestAnimationFrame`，不在滚动中读写交错布局属性。
- 高频动画限定为 `transform` 与 `opacity`；大面积 `filter`、模糊和阴影不参与动画。
- `clip-path` 只用于一次性进入与主题切换，移动端必要时直接降级为淡入。
- 不引入 GSAP、Three.js、外部字体或任何运行时依赖。

### 减弱动效

`prefers-reduced-motion: reduce` 下禁用主题空间变换、滚动揭示、平滑滚动和粘性截图切换。全部内容立即可见，主题切换仍然即时完成。

## 响应式与无障碍

- 重点验证 `320`、`360`、`412`、`768` 和 `1440` 像素宽度。
- 风格轨道可触摸滚动，不截断中文名称，不遮挡页眉或内容。
- 所有按钮至少 44 像素高，键盘焦点清晰，颜色不是唯一的选中提示。
- 标题不使用视口宽度缩放字号，字距保持 `0`。
- 文件名与 SHA-256 可换行，不产生横向溢出。
- 截图使用稳定宽高比，加载状态与切换状态不改变布局尺寸。

## 技术边界

- 保持 `docs/` 下静态、零依赖的 GitHub Pages 交付。
- `styles.css` 保留共享布局、稳定尺寸、响应式规则和基础动效，新增 `themes.css` 专门承载十套主题 token 与有限的签名构图覆盖。
- `app.js` 通过单一主题应用函数更新 `data-theme`、控件状态、持久化数据与浏览器主题色；首帧内联脚本在样式加载前恢复并校验已保存主题，避免刷新闪回默认样式。
- 保留真实截图、公开仓库地址、Release 地址、APK 元数据和隐私说明。
- 不使用渐变、玻璃拟态、装饰光球、嵌套卡片、外部统计脚本或 Cookie。
- 404 页面共享默认主题的核心变量和下载入口，不承载完整主题切换器。

## 验证清单

1. HTML、JavaScript 语法与 `git diff --check`。
2. 十套主题逐一检查首屏、故事段、下载区和页脚。
3. 桌面端与移动端截图、横向溢出、文本换行和图片加载。
4. 鼠标、触摸、键盘切换主题及持久化恢复。
5. View Transition 支持与不支持两条路径。
6. 正常动效、减弱动效、无 JavaScript、无 IntersectionObserver 四条路径。
7. 快速滚动、快速切换主题、窗口缩放时的长任务和布局抖动。
8. 复制校验值成功与失败状态。
9. 控制台错误、失败请求、404 页面与线上 GitHub Pages HTTP 状态。
10. 线上 APK 文件大小和 SHA-256 与 `v0.5.1` 发布信息一致。

## 验收标准

- 十套风格一眼可区分，不只是换色。
- 当前冲刺仪表原型完整保留为第六套。
- 主题切换不中断阅读、不回到页首、不造成布局跳动。
- 滚动叙事在桌面端具有连贯产品舞台感，在移动端仍然轻快自然。
- 所有主题的首屏都有直接下载入口，真实截图保持中心地位。
- 所有目标视口无重叠、无截断、无横向溢出。
- 无 JavaScript 和减弱动效路径仍能看到全部内容并完成下载。
- 线上页面与 APK 链接在交付前通过验证，并在 Windows 默认浏览器打开。
