# 导航与计时动效统一设计

日期：2026-08-17

## 目标

统一格记 Android/Web 界面的页面层级和计时模式切换动效，修复打点按钮在窄屏被 Flex 压缩的问题，并让学习概况中的月度热力图支持可访问、可持久化的折叠。

## 动效语言

- 直接控制反馈：160-180ms，强调即时触感。
- 页面和模式切换：320ms，使用 `cubic-bezier(.22, 1, .36, 1)`。
- 折叠内容：320ms，使用高度轨道、透明度和轻微位移组合。
- 只动画 `transform`、`opacity` 和低频折叠布局属性，不引入新动画依赖。
- `prefers-reduced-motion: reduce` 下缩短到近乎即时，仅保留状态切换。

## 二级页面

根 Tab 舞台和二级页面容器放入同一个 Vue `Transition`，以稳定 key 区分根页面与二级页面。二级 `router-view` 的组件增加 `route.fullPath` key，确保同一个 `SettingsView` 在设备直连、电脑同步之间也会触发切换。

进入二级页面时，页面从右侧轻移并淡入；返回父页面时不做夸张反向滑动，使用相同节奏的淡出和轻微缩放。现有四个根 Tab 仍由 `useSwipeTabs` 保持横向 ViewPager 动画，不改变手势逻辑。

该机制覆盖 `/overview`、`/tasks`、`/timer/history`、`/stats`、日期详情、设备直连和电脑同步，后续新增二级路由默认继承。

## 学习概况热力图

月度热力图标题区改为按钮，提供 `aria-expanded` 和 `aria-controls`。默认收起，并通过本地偏好保存用户最后一次展开状态。

内容使用 CSS grid 的 `0fr -> 1fr` 轨道过渡，配合透明度和 8px 位移。收起时内容设置 `inert`，防止不可见的月份按钮进入键盘和读屏焦点。

## 计时模式切换

计时、倒计时、番茄钟切换时，模式舞台与控制区作为一个有 key 的视图整体过渡。旧视图先淡出并轻移，新视图再从相反方向进入，时长与根 Tab 点击切换一致。活动计时期间模式按钮继续禁用，不改变业务状态。

模式选择器增加可移动的背景指示块，使用 transform 在三个等宽槽位间移动，避免只有颜色瞬间变化。

## 打点按钮

所有圆形计时按钮增加 `flex: 0 0 auto`、固定最小尺寸、`aspect-ratio: 1` 和 `box-sizing: border-box`。打点按钮保持 80x80，窄屏下不能缩成椭圆；横屏布局也使用相同约束。

## 测试

- 静态测试：路由 key、根/二级过渡、热力图折叠语义、模式过渡和按钮几何约束。
- 自动化：Web 全量测试、TypeScript、Vite 构建、Android JVM 测试和 APK 构建。
- 真机：ADB 安装后逐项点击所有二级入口，快速往返；展开/收起热力图；连续切换三种计时模式；启动秒表并检查打点按钮宽高。
- 动画 QA：检查正常动效、快速重复点击、竖屏/横屏、低动态模式、控制台错误和应用崩溃日志。

## 非目标

- 不修改任务、计时、同步和统计的数据结构。
- 不替换现有 ViewPager 手势实现。
- 不增加第三方动画依赖。
