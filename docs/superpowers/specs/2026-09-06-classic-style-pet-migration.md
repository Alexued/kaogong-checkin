# 经典格记风格宠物系统迁移设计

日期：2026-09-06

## 目标
在格记 v0.15.1 的 Vue 界面与数据架构中迁移宠物系统，保持原有青绿蓝渐变、圆角卡片、浅色/深色主题和导航体验。

## 范围
- 计时页宠物陪伴卡片与动作状态展示。
- 宠物中心、商店、装备、食品库存和喂养。
- 宠物命名、星星余额和完成奖励。
- internal-debug 测试入口与可恢复测试快照。

## 约束
- 第一阶段宠物采用独立 Pinia store 和独立本地存档；不加入旧版同步/备份协议，提供宠物专用 JSON 备份。
- 调试会话保存独立沙盒，不覆盖真实宠物存档；短番茄不写学习历史。
- 不覆盖任务、计时、背诵和同步数据。
- 正式构建不显示测试工具。
- Vite 普通 production 构建不显示测试工具；内部测试 APK 使用 `--mode internal-debug`，并由 Android `BuildConfig` 再次门控。
- 使用原版 Vue/Pinia/样式变量，不复制离线测试页。
- 首阶段不迁移打卡海报和全部跨页权限，先确保宠物核心闭环。

## 验收
- 原版首页和计时页视觉不变。
- 完成番茄钟后星星只结算一次。
- 商店购买、装备、食品库存、喂养可通过真实 UI 完成。
- 测试数据可恢复，正式构建无调试入口。
