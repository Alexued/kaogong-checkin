便签 01 / 基期量

已知现期量和增长率，怎么求基期量？

现期量 ÷（1＋增长率）。先估算数量级，再计算。

便签 02 / 增长量

增长量比较，先看什么？

先看现期量与增长率的乘积，再用百化分修正。

便签 03 / 比重

部分增长快于整体，比重怎么变？

部分增长率大于整体增长率，比重上升；反之下降。
