移动端学习记录与可选局域网伴侣说明

摘要

本资料说明格记 Android 应用与 Windows 伴侣的用途、数据边界、安装条件和下载附件。电脑同步默认由用户控制，关闭后不进行局域网发现、连接或更新查询。

一

适用范围

格记适用于需要安排每日任务、记录专注时长和进行背诵复习的个人用户。Android 应用承担主要记录工作，数据首先保存在用户设备中。

Windows 伴侣用于同一可信局域网中的电脑备份、配对和安装包提供，不是使用移动端功能的必要条件。

三

数据管理

电脑同步设有总开关。开关关闭后，应用停止 REST 请求、WebSocket、重连、UDP 发现、配对以及局域网更新检查；本地记录、服务器配置、配对信息与待同步队列保留。

关闭仅在手机保存，不扫描电脑，不发起局域网更新查询。
开启启动发现；选定服务器并配对后，才建立数据连接。
版本检查比较局域网与 GitHub 版本，只显示结果，不自动下载安装。
展开技术边界说明

每次同步生命周期使用新的 generation。关闭或更换服务器时，旧请求被取消；迟到结果不得恢复连接或更新界面。GitHub 手动检查可独立进行，但不会绕过同步总开关启动局域网活动。

四

安装办法

  1. 01

    核对平台。Android 安装 APK；Windows 10/11 x64 安装桌面伴侣。

  2. 02

    核对文件。确认文件名、版本与本页登记一致，必要时校验 SHA-256。

  3. 03

    完成授权。Android 安装仍由系统请求用户确认；局域网配对使用电脑显示的六位码。

展开局域网更新流程
  1. 用户打开电脑同步并选定服务器。
  2. 移动端读取局域网安装包版本，同时查询 GitHub Release。
  3. 比较三段语义版本，同版本优先显示局域网来源。
  4. 用户点击下载后，再由 Android 系统确认安装。
