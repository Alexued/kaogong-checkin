## 5. 发现并修复的缺陷

| 编号 | 缺陷 | 修复与回归 |
| --- | --- | --- |
| BUG-01 | 展开子任务后，底部数量任务“＋”与右下角 FAB 重叠，点击错误打开新增面板 | 有任务时隐藏 FAB，顶部提供新增按钮；真机数量 `0/3 -> 1/3 -> 2/3 -> 1/3 -> 3/3` 回归通过 |

| BUG-04 | 删除确认称打卡记录保留，但实际会删除进度并解除计时关联 | 文案改为“打卡进度会一并删除，计时记录会保留但取消关联”；UI 树和数据行为一致 |

| 指标 | 结果 |
| --- | --- |
| 总帧数 | 464 |
| Janky frames | 96（20.69%） |
| 50 / 90 / 95 / 99 分位 | 14 / 18 / 19 / 44 ms |
| Missed Vsync | 7 |
| Slow UI thread | 19 |
| TOTAL PSS | 166,622 KB |
| TOTAL RSS | 297,404 KB |

页面切换压力场景的 jank 比例偏高，但中位数 14 ms，未观察到卡死、空白帧、触控失效或动画后状态残留。该数值保留为后续性能优化基线，不宣称“零卡顿”。
