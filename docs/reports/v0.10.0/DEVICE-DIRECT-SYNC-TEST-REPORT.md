## 3. 实现验收范围

### 3.1 设备直连

- Android NSD 服务类型：`_kgc-sync._tcp.`。
- TCP 使用 4 字节长度前缀和 JSON 帧，快照上限 8 MiB。
- 接收方每次传输均显示应用内确认框，不复用上一次授权。
- 配对码为六位数字，按会话轮换，并有错误次数限制。
- 快照同时校验 UTF-8 字节数、SHA-256、协议版本和 v3 领域状态。
- 接收采用完整替换；替换前原子保存恢复点，最多保留最近 5 份。
- 接收或恢复后电脑同步保持关闭，旧电脑同步队列归档，避免两条替换链路竞争。
- 发现开关和主动搜索开关相互独立；应用离开前台时关闭主机和发现，返回前台后按偏好恢复。
- 支持 NSD、手动 IPv4 地址 + 六位码、二维码深链三种连接入口。

### 3.2 应用内确认框

- 任务删除、计时记录删除、训练记录清空、设备发送/接收和恢复点恢复均使用统一应用内确认面板。
- 确认面板支持危险/警告语义、取消、确认、Android 返回键和请求排队。
- 自动化扫描确认业务代码不再调用 `window.confirm`。

### 3.3 SwiftPixelGrid 风格反馈

Web/Android 不能直接编译 SwiftUI 库，本项目按 SwiftPixelGrid 的 Pattern 分组、九宫格离散帧和绝对时间播放语义实现等价组件：

| 场景 | Pattern | 真机结果 |
| --- | --- | --- |
| 任务/子任务打卡 | `confirm` | 通过 |
| 新建任务 | `arrival` | 通过 |
| 删除任务 | `dissolve` | 通过，播报“打卡项已删除” |
| 倒计时自然完成 | 完成反馈 | 通过，播报“倒计时完成” |
| 模式切换 | 模式反馈 | 通过 |

冷启动阶段主界面与右下角新增按钮共用启动外壳状态；新增按钮不会先于其他界面单独出现。

## 7. 发现并修复的缺陷

| 编号 | 缺陷 | 修复与回归 |
| --- | --- | --- |
| BUG-01 | Android WebView 解析 `kgc://peer-connect` 时 `hostname` 为空，二维码深链无法识别 | 从 `pathname` 兼容提取路由；真机地址和六位码预填通过 |
| BUG-02 | 桌面协议模拟器中文字符串损坏且 TCP 帧头未保证完整读取 | 修复字符串，新增 `read_exact()` 和版本/SHA/大小注错参数；六条协议日志符合预期 |
| BUG-03 | 恢复前保护点对同一状态重复导出，第二次导出失败后无法进入恢复 | 改为单次一致性导出，恢复包与摘要同修订；含 9 条队列的真机恢复通过 |
| BUG-04 | Capacitor `SystemBars` 在 DOM 建立前重复注入安全区 CSS，启动固定产生空节点 Console Error | 配置 `insetsHandling: disable`，保留 MainActivity 原生 Insets；最终错误日志为空 |
