## 2. 本版方案选择

| 需求 | 本版采用 | 未采用方案 | 选择原因 |
| --- | --- | --- | --- |
| 今日页层级 | 任务在首屏，驾驶舱独立为 `/overview` | 继续把指标放在任务上方 | 高频动作优先，打开即可处理任务 |
| 任务快捷操作 | 长按触点锚定悬浮菜单 | 底部操作抽屉 | 操作与目标位置关联更直接 |

## 9. 数据保护与日志

- 两台手机最终均不存在 `v0.14.0 临时 QA 任务`。
- 没有执行 `pm clear`、卸载、设备重启或恢复出厂操作。
- 最终 logcat 中没有 `FATAL EXCEPTION` 或 `AndroidRuntime` 崩溃。
- Android 13 记录到系统找不到 Custom Tabs 服务的环境警告；应用内 APK 更新主路径使用原生下载与系统安装器，本轮功能不受影响。
- ADB 与 CDP 截图、脚本和设备日志在验收期间保存于本地临时目录，发布前已清理，不提交包含设备信息的证据文件。

## 10. 残余风险

- APK 沿用 Android Debug 证书，仅适合当前 `internal-debug` 更新渠道，不作为应用商店正式签名。
- Windows 安装程序未商业签名，用户应从 GitHub Release 下载并核对 SHA-256。
- 题库图片来自外部 CDN；本版已提供有限回退，但完全离线时仍会显示“原题图片暂时无法加载”。文字题、答案和逐题解析保存在应用包内。
- 题库动态块体积约 6.83 MB；它不进入首屏主包，但首次打开完整题库仍受设备解压和解析性能影响。
- 本轮按要求未重启手机，因此没有执行设备重启后的开关恢复场景；覆盖安装、应用冷启动和进程重建已执行。

本报告只记录实际执行的测试，不把未执行场景写成已通过。
