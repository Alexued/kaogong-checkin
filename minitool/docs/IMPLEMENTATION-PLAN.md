# 实施计划

已确认新建格记及精简题库，不覆盖已有小工具。环境没有 writing-plans skill，使用本文件记录可执行步骤。

1. 独立构建入口，复用现有 Vue 编译链和领域模块，构建期阻止原生与联网模块进入产物。
2. 稳定章节抽样、保留完整题目字段，200 题和 512 KiB 双限制；测试不变性、确定性和图片依赖。
3. 替换同步为纯本地写入；学习记录与钱包沿用同步 localStorage 原子写入，签名身份使用 IndexedDB。写入成功后才更新界面，失败不消耗奖励。此处明确细化原设计：不强制把同步钱包重写为异步存储。
4. 保留经典页面，设置页移除更新与同步；页内文本备份替代下载及 TXT 选择器。
5. 用户手势触发图片/相机扫码，纯 JS 解码、停用时关闭媒体；心愿仍使用原验签。能力不足拒绝签发，不使用弱随机或弱签名。
6. Canvas 打卡海报、相册保存与发笔记桥接；普通浏览器只预览，不假报成功。
7. 构建为经典 IIFE、局部 ES2017 运行时兼容和 CSS 基线处理；移除 Worker/剪贴板/网络等禁用能力。
8. 运行领域与平台测试、实际页面验证、官方审计，任何阻断项失败不上传。生成可追溯 ZIP、校验摘要与报告后进入平台体验。
